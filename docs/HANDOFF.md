## 3. プロトコル要点（V3）

- デバイス名: `47L121000`（Web版は前方一致 `47L`）
- Service `0x180C`: Write `0x150A`（B0/BF, 20バイト）、Notify `0x150B`（B1）
- Service `0x180A`: Battery `0x1500`（Read/Notify）
- Base UUID: `0000xxxx-0000-1000-8000-00805f9b34fb`
- **B0** は100msごとに送り続ける。構成は `[0xB0, seq<<4 | mode, 強度A, 強度B, 周波数A×4, 強度波形A×4, 周波数B×4, 強度波形B×4]`
- mode は2bitずつ（上位=A、下位=B）。`00`変更なし / `01`相対増 / `10`相対減 / `11`絶対値
- seq は 1〜15。非ゼロで強度を変えたら、B1 の返答を待ってから次の強度変更を送る
- **BF**（7バイト、本体の不揮発メモリに保存）: ソフトリミットA/B、周波数バランスA/B、パルス幅バランスA/B。接続のたびに必ず再送する
- 周波数入力値: 10〜240。周期ms → 入力値は `〜100ms: そのまま` / `〜600ms: (x-100)/5+100` / `〜1000ms: (x-600)/10+200`
- チャンネルのどれかのバイトが不正（強度>100など）だと、そのチャンネルの4サンプルは破棄される

## 7. 安全上の決めごと

- ソフトリミットの初期値は60。使う人が自分で安全な値に設定し直す
- 接続後の強度は常に0から開始する
- 緊急停止ルートは通常操作と独立させておく
- 切断・エラー時は安全側（強度0）に倒す
- 長時間の連続使用や、同じ部位への長時間の使用は避ける（公式マニュアルの注意に従う）
