# Coyote Controller

DG-Lab Coyote 3.0 を、公式アプリを使わずに BLE で直接操作する自作コントローラーです。

- **Web版（Android Chrome）**: リポジトリ直下の `index.html`。GitHub Pages で公開し、Chrome で開いて使います。ホーム画面に追加すると PWA として起動できます。
- **M5Stack Core2版**: `m5/CoyoteController.ino`（M5Unified + NimBLE-Arduino 2.x）。現在は保留中です。

経緯・プロトコル要点・未検証事項は [docs/HANDOFF.md](docs/HANDOFF.md) を参照してください。

## 安全について

- ソフトリミットの初期値は 60 です。使う人が自分で安全な値に設定し直してください。
- 接続後の強度は常に 0 から始まり、上げるときは 1 回につき最大 +5 ずつ上がります。
- 緊急停止ボタン、切断、画面が隠れたとき（アプリ切り替え・画面オフ）は強度 0 になります。
- 両版とも実機では未検証です。最初は必ず低い強度で確認してください。
- 長時間の連続使用や、同じ部位への長時間の使用は避けてください（公式マニュアルの注意に従ってください）。

## 利用条件

DG-LAB が公開している Bluetooth プロトコル（V3）を使っています。このプロトコルの利用は**非商用に限られます**。商用利用には Dungeon Lab の許可が必要です。
